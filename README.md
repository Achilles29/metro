# Setimbang

Sistem pendaftaran tera dan informasi pengawasan Kabupaten Rembang, berbasis CodeIgniter 3.

Dokumentasi kebutuhan dan skema awal berada di `docs/`. Catatan implementasi dan operasi berada di `docs/05_implementasi_dan_operasional.md`; alur WhatsApp, GIS, dan teknisi eksternal ada di `docs/09_setimbang_whatsapp_gis_teknisi.md`; revisi terbaru berdasarkan PDF 13 November 2026 beserta format tiga spreadsheet ada di `docs/11_revisi_website_20261113.md`. Panduan pengaturan Google untuk pemilik akun ada di `docs/12_panduan_pemilik_google.md`. Kredensial administrator awal disimpan di `docs/AKSES_ADMIN.md` pada server dan tidak dimasukkan ke Git.
